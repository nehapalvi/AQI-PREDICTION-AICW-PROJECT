# 🌿 AQI Prediction System

A Machine Learning web app to predict **Air Quality Index (AQI)** using **XGBoost**, with an interactive dashboard for data visualization.

## 🚀 Live Demo

https://aqi-prediction-aicw-project-cut2q4cnxmyh8pgkaipe4c.streamlit.app/

---

## ✨ Features

* AQI Dashboard (trends, monthly analysis, pollutant comparison)
* Real-time AQI Prediction
* City-wise filtering
* Interactive visualizations (Plotly + Streamlit)

---

## 🛠 Tech Stack

* Python
* XGBoost
* Pandas, NumPy
* Plotly
* Streamlit

---

## 📂 Structure

```
PROJECT-DEMO/
```

## ⚙️ Run Locally

```bash
git clone https://github.com/nehapalvi/AQI-PREDICTION-AICW-PROJECT.git
cd AQI-PREDICTION-AICW-PROJECT
pip install -r requirements.txt
streamlit run main.py
```
